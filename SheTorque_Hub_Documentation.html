1. Abstract

SheTorque Hub is a mobile application built with Flutter and native Android code that transforms a smartphone into an intelligent crash detection and emergency alert system for motorcycle and two-wheeler riders. The application leverages the device's built-in accelerometer via IMU sensor fusion to continuously monitor G-force in real time. When a sudden impact exceeding a configurable threshold (default 25 G) is detected, the app triggers a multi-layered emergency response protocol: an audible siren alarm, a 90-second countdown allowing the rider to cancel if it is a false positive, and — upon countdown expiry without cancellation — fully automatic background dispatch of an emergency SMS containing the rider's precise GPS coordinates to a pre-configured emergency contact, requiring zero human interaction.

2. Introduction

2.1 Problem Statement

Two-wheeler accidents are among the leading causes of road fatalities worldwide. In many crash scenarios, the rider is incapacitated and unable to call for help. Existing commercial solutions are often hardware-dependent and prohibitively expensive. There is a clear need for a software-only solution that leverages existing smartphone hardware to natively and autonomously alert emergency contacts with location information without requiring the injured rider to press "Send".

2.2 Objectives

  • Detect potential crash events in real time using the smartphone's built-in accelerometer.
  • Provide an audible siren alarm to draw immediate attention to the scene.
  • Implement a configurable countdown period (90 seconds) to avoid false-positive SOS alerts.
  • Automatically send an emergency SMS via native Android APIs with the rider's GPS location upon countdown expiry, with no user interaction.
  • Design a simple, high-contrast UI that works under stress and with riding gloves.
  • Ensure the alarm plays even when the phone is in silent or vibrate mode.

2.3 Scope

The current scope covers Android deployment via Flutter and native Kotlin components. The app requires the device to have an accelerometer, GPS, SMS capability with runtime permissions mapped, and an internet connection (for siren audio streaming).

6.6 Fully Automatic SOS Emergency Alert System

Unlike basic systems that simply open the SMS app for the user to press 'Send', SheTorque Hub uses a direct native Platform Channel to securely hand off the payload to the Android OS. The OS then natively dispatches the SMS entirely in the background.

  1. GPS Acquisition: High-accuracy position via Geolocator.
  2. MethodChannel Invocation: Flutter calls _smsChannel.invokeMethod('sendSms') passing the contact and pre-composed message.
  3. Native SmsManager: Over in MainActivity.kt, the Android OS SmsManager is utilized. It correctly breaks the payload via divideMessage and sends it silently using sendMultipartTextMessage.

6.8 Permissions & Runtime Handling

Modern Android architectures require dynamic permissions. During `initState`, the app dynamically asks the user for:

  • ACCESS_FINE_LOCATION (via GeoLocator plugin)
  • SEND_SMS (via Permission Handler plugin)

class SensorFusionHub extends StatefulWidget {
  const SensorFusionHub({super.key});
  @override
  _SensorFusionHubState createState() => _SensorFusionHubState();
}

class _SensorFusionHubState extends State<SensorFusionHub> {
  final String emergencyContact = "+916360826795";
  final double crashThreshold = 25.0; 
  
  bool isCrashDetected = false;
  bool isSosSent = false;
  int countdownSeconds = 90;
  double liveGForce = 0.0;
  
  Timer? _displayTimer;
  final AudioPlayer _audioPlayer = AudioPlayer();
  StreamSubscription? _accelerometerSubscription;

  // Platform channel for native SMS sending
  static const _smsChannel = MethodChannel('com.shetorque.hub/sms');

  @override
  void initState() {
    super.initState();
    _setupAudio();
    _checkPermissions();
    _startListening();
  }

  Future<void> _setupAudio() async {
    try {
      await _audioPlayer.setAudioContext(AudioContext(
        android: const AudioContextAndroid(
          usageType: AndroidUsageType.alarm,
          contentType: AndroidContentType.sonification,
          audioFocus: AndroidAudioFocus.gain,
        ),
      ));
      await _audioPlayer.setSource(UrlSource('https://crude-silver-wzcjnmjo5u.edgeone.app/emergency_alarm_siren.mp3'));
    } catch (e) {
      print("Audio Setup Error: $e");
    }
  }

  Future<void> _checkPermissions() async {
    await Geolocator.requestPermission();
    await Permission.sms.request();
  }

  void _startListening() {
    _accelerometerSubscription = accelerometerEvents.listen((AccelerometerEvent event) {
      double g = sqrt(event.x * event.x + event.y * event.y + event.z * event.z);
      setState(() { liveGForce = g; });
      if (!isCrashDetected && !isSosSent && g > crashThreshold) {
        _triggerCrashProtocol();
      }
    });
  }

  void _triggerCrashProtocol() {
    setState(() {
      isCrashDetected = true;
      countdownSeconds = 90;
    });
    _audioPlayer.setReleaseMode(ReleaseMode.loop);
    _audioPlayer.resume(); 

    _displayTimer = Timer.periodic(const Duration(seconds: 1), (timer) {
      setState(() {
        if (countdownSeconds > 0) {
          countdownSeconds--;
        } else {
          _displayTimer?.cancel();
          _sendFinalSOS(); 
        }
      });
    });
  }

  Future<void> _sendFinalSOS() async {
    try {
      Position position = await Geolocator.getCurrentPosition(desiredAccuracy: LocationAccuracy.high);
      String mapLink = "https://www.google.com/maps/search/?api=1&query=${position.latitude},${position.longitude}";
      String message = "EMERGENCY: SheTorque Hub detected a crash! Rider is unresponsive. Location: $mapLink";

      // Auto-send native SMS
      await _smsChannel.invokeMethod('sendSms', {
        'phone': emergencyContact,
        'message': message,
      });

      _onSosSent();
    } catch (e) {
      print("SOS Error: $e");
    }
  }

  void _onSosSent() {
    _audioPlayer.stop();
    setState(() {
      isCrashDetected = false;
      isSosSent = true;
    });
  }

  void _cancelSOS() {
    _displayTimer?.cancel();
    _audioPlayer.stop();
    setState(() {
      isCrashDetected = false;
      isSosSent = false;
    });
  }

  @override
  Widget build(BuildContext context) {
    Color bgColor = Colors.black;
    if (isSosSent) bgColor = Colors.green.shade900;
    else if (isCrashDetected) bgColor = Colors.red.shade900;

    return Scaffold(
      backgroundColor: bgColor,
      body: Center(
        child: isSosSent ? _buildSuccessUI() : (isCrashDetected ? _buildCrashUI() : _buildNormalUI()),
      ),
    );
  }

  // UI Components omitted for brevity...
  Widget _buildNormalUI() { return Container(); }
  Widget _buildCrashUI() { return Container(); }
  Widget _buildSuccessUI() { return Container(); }
}

7.2 Native Android Handler (MainActivity.kt)

package com.example.shetorque_hub

import io.flutter.embedding.android.FlutterActivity
import io.flutter.embedding.engine.FlutterEngine
import io.flutter.plugin.common.MethodChannel
import android.telephony.SmsManager
import android.os.Build

class MainActivity : FlutterActivity() {
    private val CHANNEL = "com.shetorque.hub/sms"

    override fun configureFlutterEngine(flutterEngine: FlutterEngine) {
        super.configureFlutterEngine(flutterEngine)

        MethodChannel(flutterEngine.dartExecutor.binaryMessenger, CHANNEL)
            .setMethodCallHandler { call, result ->
                if (call.method == "sendSms") {
                    val phone = call.argument<String>("phone")
                    val message = call.argument<String>("message")

                    if (phone != null && message != null) {
                        try {
                            val smsManager = if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.S) {
                                getSystemService(SmsManager::class.java)
                            } else {
                                @Suppress("DEPRECATION")
                                SmsManager.getDefault()
                            }

                            val parts = smsManager.divideMessage(message)
                            smsManager.sendMultipartTextMessage(phone, null, parts, null, null)

                            result.success(true)
                        } catch (e: Exception) {
                            result.error("SMS_ERROR", e.message, null)
                        }
                    } else {
                        result.error("INVALID_ARGS", "Phone and message are required", null)
                    }
                } else {
                    result.notImplemented()
                }
            }
    }
}

10. Limitations

  2. No background execution: The app must be in the foreground to monitor the accelerometer.
